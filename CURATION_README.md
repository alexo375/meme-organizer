# Инструкция по доразметке датасета (Gold Curation)

Привет! В этой ветке подготовлена удобная веб-среда для финальной доразметки мемов и реакций.
Большая часть датасета уже проверена (~220 мемов). Осталось просмотреть **~90 файлов** в статусе "Ожидают".

---

## Быстрый запуск через Docker (Рекомендуется)

Всё упаковано в контейнер и поднимается одной командой:

```bash
docker compose up -d --build
```

После этого открой в браузере: **http://localhost:8080**

(Папка `./data` смонтирована внутрь контейнера, поэтому все правки автоматически сохраняются на диск).

---

## Запуск без Docker (через uv, если установлен Python 3.13)

```bash
uv sync
uv run meme-label curate
```

Сервер откроется на **http://localhost:8080**.

---

## Что делать в интерфейсе

1. Вверху переключись на вкладку **«Ожидают»** — там будут показываться только неразмеченные карточки.
2. Для каждой карточки:
   - **User Caption**: короткая емкая подпись (панчлайн, 2–6 слов), передающая эмоцию/смысл.
   - **Цитата / OCR / Текст речи**: если в видео или на картинке есть ключевая фраза (например, «Твой софт — говно», «По машинам»), проверь ее точность.
   - **Теги и Поисковые запросы**: поправь, если Gemini придумала нейроводу или ошиблась.
   - Если мем годный $\rightarrow$ жми **«✓ В Gold»** (сохранится и перейдет в подтвержденные).
   - Если мем мусорный, непонятный или слишком заумный $\rightarrow$ жми **«✕ Брак»** (он не пойдет в релиз).
   - Если явный дубль или файл битый $\rightarrow$ жми красную кнопку **«Удалить файл»**.
3. Когда все «Ожидают» закончатся:
   - Нажми в шапке кнопку **«💾 Экспорт в data/gold/»**.
   - Сделай коммит и залей пулл-реквест:
     ```bash
     git add data/
     git commit -m "feat(dataset): complete gold curation dataset"
     git push origin <твоя-ветка>
     ```
